# EventGuard 生产就绪与架构优化清单

> 本文只描述当前状态，不区分历史日期。
> 优先级：**P0** 上线前必须完成；**P1** 稳定运行后尽快完成；**P2** 长期演进。
> 状态：**已完成**、**部分完成**、**未完成**。

## 一、数据安全与恢复

| 事项 | 优先级 | 状态 | 当前方案 / 后续建议 |
|---|---|---|---|
| PostgreSQL 备份 | P0 | 已完成 | `scripts/backup-db.sh` 使用 `pg_dump` custom 格式并保留备份。 |

| 异地备份 | P0 | 未完成 | 增加对象存储或远端备份，并验证跨主机恢复。 |

## 总结

当前系统的事件驱动、事件溯源、CQRS、幂等控制和人工审批边界基本合理，适合单机验证和中小规模内部使用。主要生产缺口集中在单实例基础设施、进程内状态、契约与告警可靠隔离、外部副作用恢复以及异地容灾。

推荐顺序：**数据恢复与安全边界 → 健康检查和失败隔离 → 契约 quarantine → Outbox → 共享状态与高可用 → 容量和故障切换演练**。
