# EventGuard v1.1.0 (AI 主动层)

在 v1.0.0 被动链路（检测 → 告警 → 建议）之上补齐 AI 主动层，主线叙事：**被动检测 → 主动预测 → 自主处置 → 可复盘**。

## 核心能力
- **LLM 提供商适配**：Anthropic/OpenAI 双格式自动探测（兼容 DeepSeek `/anthropic` 端点），JSON 模式 + 工具调用归一化。
- **多轮 NL 对话**：缺参反问、补参续查、同会话上下文复用。
- **告警去重 + 风暴抑制**：幂等门控 + 看板聚合视图（按规则/订单聚类）。
- **LLM 输出可靠性**：结构化输出 + 错误反馈重试 + 证据核验（防编造）。
- **AI 可观测性**：LLM 缓存（TTL+LRU）、token/调用指标、调用 trace + `X-Trace-Id`。
- **事件流终局预测**：从订单早期事件预测终局（CLOSED/CANCELLED/REFUNDED/STUCK），RandomForest 准确率 0.71。
- **ReAct 根因分析 agent**：多轮工具调用收集证据 → 结构化报告 + 分析过程 trace。
- **补偿审批闭环**：AI 建议 → 一键发 Saga → 高风险自动落审批单 → 审批页人工决策。
- **运营周报 / 订单故事线**：异常聚合 + LLM 复盘 + 单订单可读故事。
- **相似案例检索**：零依赖加权相似度 + 处置状态；可作 few-shot 注入根因 prompt。

## 已知限制 / 说明
- **写操作人工在环**：AI 只给建议，补偿执行需人工审批（高风险步自动落单），agent 不自主写补偿。
- **压测兼容**：`/ai/query` 响应结构向后兼容；不新增自动告警，控制组 FP 口径不变。
- **部署落后**：运行镜像（2026-08-08 前）未含本版代码，需 `docker compose up -d --build`；同日已构建新 AI 镜像。
- 预测标签来自合成数据，STUCK 判定与 P002 语义一致；模型文件已提交（1.3MB）。
